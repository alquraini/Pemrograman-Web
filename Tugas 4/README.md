# Portal Akademik — Tugas Mandiri Modul 4

Proyek ini merupakan antarmuka web **Portal Akademik** yang dibuat untuk memenuhi Tugas Mandiri Modul 4 mata kuliah Pemrograman Web[cite: 2]. Web ini menampilkan informasi ringkas mengenai data mahasiswa, indeks prestasi, serta status akademik dengan tampilan responsif[cite: 2].

---

## Fitur Utama

- **Header Navigasi Responsif:** Dilengkapi dengan tombol *toggle* (hamburger menu) untuk tampilan layar seluler/ponsel[cite: 1, 2].
- **Kartu Informasi Mahasiswa:** Menampilkan data dasar mahasiswa seperti Nama, NIM, Program Studi, dan Status Akademik[cite: 2].
- **Ringkasan Ringkas & Statistik:** Ringkasan nilai IPK, total SKS yang diambil, serta status pembayaran UKT[cite: 2].
- **Desain Adaptif:** Tata letak fleksibel yang menyesuaikan tampilan desktop maupun perangkat *mobile*[cite: 1, 2].

---

## Teknologi yang Digunakan

- **HTML5** & **CSS3** (Kustom layout & gaya[cite: 1, 2])
- **Bootstrap 5.3.3** (Melalui CDN[cite: 2])
- **Google Fonts** (*Inter*[cite: 2])
