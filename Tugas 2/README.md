# Tugas Module 2 — Halaman Daftar Publikasi Penelitian Dosen

## Deskripsi
Halaman web statis (HTML5) yang menampilkan daftar publikasi ilmiah dosen,
disusun sebagai pemenuhan spesifikasi standardisasi konten HTML5.

## File
- `02-tugas-standardisasi-konten.html` — halaman utama tugas

## Spesifikasi yang dipenuhi
- Struktur dokumen HTML5 standar dan valid menurut W3C
- Tabel publikasi kompleks dengan colspan dan rowspan, lengkap dengan
  thead, tbody, tfoot, dan atribut scope
- Deskripsi bidang keahlian: ordered list di tingkat utama,
  unordered list bersarang di tingkat dalam
- figure dan figcaption untuk diagram alur metodologi riset
- Deskripsi riset memuat lebih dari tiga entitas karakter khusus

## Cara membuka
Buka `02-tugas-standardisasi-konten.html` langsung di browser.
Pastikan file `Logo-Resmi-Unhas-1.png` berada di folder yang sama.
