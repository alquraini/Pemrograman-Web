## Deskripsi
Repositori ini berisi rancangan basis data relasional untuk sistem peminjaman
buku perpustakaan kampus, mencakup entitas Mahasiswa, Buku, Penerbit, dan
Transaksi Peminjaman. Isi lengkap tugas ada di berkas
`06-tugas-pemodelan-database.md`.

## Isi Berkas
| Berkas | Keterangan |
|---|---|
| `06-tugas-pemodelan-database.md` | Dokumen utama: entitas, atribut, normalisasi UNF-3NF, rancangan tabel, dan diagram ERD |
| `ERD.png` | Hasil ekspor diagram ERD dari kode Mermaid |
| `README.md` | Catatan ini |

## Tools yang Digunakan
| Kebutuhan | Tools |
|---|---|
| Penulisan dokumen | Visual Studio Code (format Markdown) |
| Pembuatan diagram ERD | Mermaid (`erDiagram`) |
| Pengecekan sintaks dan ekspor gambar ERD | [Mermaid Live Editor](https://mermaid.live) |
| Pratinjau Markdown | Pratinjau bawaan VS Code |
| Asisten AI | Claude (Anthropic), model Claude Sonnet 5.5 |

## Disclaimer Penggunaan AI
Dalam pengerjaan tugas ini saya menggunakan **Claude (Anthropic)** sebagai
alat bantu. Rincian penggunaannya:

**Bagian yang dibantu AI**
- Draf identifikasi entitas, atribut, Primary Key, dan Foreign Key.
- Draf simulasi normalisasi dari UNF ke 1NF, 2NF, dan 3NF.
- Draf rancangan tabel akhir beserta tipe datanya.
- Penulisan kode diagram Mermaid dan perbaikan sintaksnya ketika muncul error.

**Yang saya lakukan sendiri**
